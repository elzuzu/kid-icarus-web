# Kid Icarus — L'Ascension (remake de fan, jouable dans le navigateur)

Version jouable : https://elzuzu.github.io/kid-icarus-web/ (stage 1-1 direct : `?scene=stage&debug=1`)

Projet de fan non commercial, en cours de developpement. *Kid Icarus* est une marque de
Nintendo ; ce projet n'est ni affilie ni approuve par Nintendo. Images, musiques, voix et
bruitages sont generes pour ce projet ; aucune ressource du jeu d'origine n'est incluse.

Commandes : fleches ou ZQSD (WASD en QWERTY) pour bouger, Espace pour sauter (maintenu : vol
plane), J ou clic gauche pour tirer (devant, ou vers le haut en tenant haut ; accroupi : tir au
ras du sol), Maj pour l'esquive, E pour la melee, 1 et 2 pour les pouvoirs, F pour l'Eau de vie,
Entree ou C (ou haut devant une porte) pour interagir, Echap pour la pause. Manette geree.
